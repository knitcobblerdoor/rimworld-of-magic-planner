## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **School Browser** | Browse all magic schools with abilities and unlock requirements |
| **Build Planner** | Plan ability paths and stat investments for magic pawns |
| **Mana Calculator** | Estimate mana pool and regeneration for planned pawn builds |
| **Synergy Guide** | Reference list of magic ability combinations with strong synergies |
